# The Book Machine — Hub Site

A small static site to share what you're building: a **Home** page, an **Updates / Journal**
feed pulled from Notion, and a **Resources** page. No frameworks, no build step beyond a
one-line sync. Hosts free on GitHub Pages (and works on Railway too).

## How it works

You write journal entries in a Notion database. A sync script reads them with a secret
token and writes them into `data/entries.json`. The site reads that JSON file — so the
**published site never contains your secret token**, and stays 100% static.

```
Notion DB  ──(sync-notion.js, uses secret token)──►  data/entries.json  ──►  the site reads it
```

Only entries with **Status = Published** appear on the site, so you can keep drafts private.

## Files

| File | What it is |

## The Notion database

Already created for you: **"Book Machine Journal"**.
Database ID: `ef77c7904a4643c7a91b97d1e29c9d55`

Properties:

- **Title** — entry title
- **Date** — date of the entry
- **Body** — the entry text
- **Project** — which tool (Book Machine, Seedsmith, F1, Spices, Author Workbench, …)
- **Type** — Journal / Milestone / Screenshot / Resource
- **Status** — Published / Draft (only **Published** shows on the site)
- **Screenshot** — optional image
- **Link** — optional external link

## One-time setup: get a Notion token

1. Go to <https://www.notion.so/my-integrations> → **New integration** → name it
   (e.g. "Book Machine Hub"), pick your workspace, **Read content** is enough.
2. Copy the **Internal Integration Secret** (starts with `ntn_` or `secret_`).
3. In Notion, open the **Book Machine Journal** database → top-right **•••** →
   **Connections** → add your new integration. (Without this step the API returns 404.)

Keep the token private. Never commit it. `.gitignore` already excludes `.env`.

## Refresh the journal (run the sync)

Requires Node 18+.

macOS / Linux:

```bash
cd hub
NOTION_TOKEN=ntn_your_token_here node scripts/sync-notion.js
```

Windows PowerShell:

```powershell
cd hub
$env:NOTION_TOKEN = "ntn_your_token_here"
node scripts/sync-notion.js
```

This rewrites `data/entries.json`. Commit and push to publish.

## Preview locally

Because the site fetches a JSON file, open it through a tiny local server (not by
double-clicking the HTML):

```bash
cd hub
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy to GitHub Pages

**Simple way:** push the site to a repo, then **Settings → Pages → Source: Deploy from
a branch** (e.g. `main` / root). Re-run the sync and push whenever you want to update.

**Hands-off way (recommended):** use the included GitHub Action.
1. **Settings → Secrets and variables → Actions** → add secret `NOTION_TOKEN`.
2. **Settings → Pages → Source: GitHub Actions.**
3. The workflow syncs from Notion and deploys on every push, plus once a day.
   If your site lives in a subfolder, edit the two marked paths in
   `.github/workflows/sync-and-deploy.yml`.

## A note on screenshots

Images you attach to the Notion **Screenshot** field are hosted by Notion with URLs that
**expire after about an hour**. So either:

- run the sync as part of every deploy (the GitHub Action does this), **or**
- paste a permanent external image URL into the Screenshot field instead.
